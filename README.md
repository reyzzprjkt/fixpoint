## Prinsip proyek
1. Satu sumber kebenaran untuk setiap keputusan.
2. Kebutuhan yang belum diputuskan ditandai `TBD`.
3. Setiap perubahan harus dapat ditelusuri ke requirement, catatan perubahan, pengujian, dan bukti yang relevan.
4. Status implementasi hanya boleh disebut selesai atau terverifikasi setelah diperiksa secara nyata.
5. Jangan menyimpan secret, token, atau data pelanggan sensitif dalam dokumentasi dan screenshot.
