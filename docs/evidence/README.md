# Evidence Directory

Simpan bukti verifikasi aktual di subfolder berdasarkan change ID.

Contoh:
`docs/evidence/2026-10-28-001-service-ticket-foundation/`

Bukti dapat berupa screenshot, test report, output migrasi yang aman, atau laporan pemeriksaan. Jangan commit secret, token, data pribadi nyata, atau log yang tidak disanitasi.

Jangan membuat folder bukti seolah-olah pengujian sudah dilakukan. Bukti hanya dibuat ketika perubahan terkait benar-benar diuji. Jika bukti belum tersedia, catat status dan alasannya di change record.
